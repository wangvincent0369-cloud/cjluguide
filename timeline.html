认识 你的宿舍

  • 房型：西区5人间、东区4人间，上床下桌，独立卫生间+阳台
  • 床铺尺寸：长约 200cm、宽约 86cm（A床 86.5cm，各楼栋略有差别）；床垫买 0.9×2.0m、床帘宽度买 0.85m 最稳（开学后网购寄到驿站一样收得到）
  • 🛏️ 床垫、床帘、洗漱这些怎么买 → 到校再买那一栏 →
  • 住宿费：五人间1200元/年，四人间1600元/年
  • 空调：有，需付租赁费
  • 热水器：独立卫生间内配电热水器
  • 洗浴热水：24 小时不间断免费供应（不用办水卡，随时都能洗）
  • 门禁：没有电子门禁，是宿管阿姨关门 —— 每天 22:30 关门（不分周末），晚归会被阿姨说
  • 熄灯：工作日 23:00、周末 23:30，但只是关灯，一点电都不会断（插座、空调照常用）
  • 违章电器：规矩就一条 —— 发热类 1200W 以下能用、超过的不让用（热得快、电热褥、取暖器、电热锅、冰箱一般都超；电吹风、卷发棒/夹板看功率）。查到扣寝室分，还连坐扣每个人的德育分
  • 电费：寝室自行分摊，在钉钉→计量钉里电费充值

认识 食堂 & 吃饭

  • G3食堂（东区）："G3大酒店"，全国高校百佳餐厅。一楼二楼大众菜+各地风味，三楼精品快餐+独立清真区域
  • F16食堂（西区）、T1食堂（东区）
  • 听沙美食餐厅：超多店家入驻，早餐到宵夜，还有免费点歌台
  • 营业时间：早餐6:30-8:30，午餐11:00-13:30，晚餐17:00-19:30
  • 高峰 11:30-12:30 / 17:30-18:30，错峰去不排队
  • 付款：钉钉内计量钉付款码 / 微信支付宝直接扫都行
  • 咖啡：瑞幸（方圆楼北楼二楼）+ 量小驿（翔宇楼）

认识 快递 & 超市

  • 收货地址：浙江省杭州市钱塘区学源街258号中国计量大学（310018）
  • 取件点就两个：
    ① 菜鸟驿站 —— 在 F2 楼下，宿舍区从内、从外都能进
    ② 妈妈驿站 —— 从 F2 往西走（按高德地图的方位：上北下南、左西右东），过一个斑马线就到了

  • 买日用品去翔宇楼地下超市，种类全，水果也有

你可能不知道

  • 校园面积1580亩，宿舍到教学楼步行约10-15分钟（1楼约10分钟，4-5楼约15分钟）
  • 校内有电动车充电桩，拿快递骑电动车很实用；校外有共享电动车，出行方便
  • 校门口有共享单车，去地铁/商场方便

开学第一个月
9月 - 10月

必知 绩点5.0制 · 比你想的重要

  • 中量大是5.0制，不是4.0制！公式：绩点 = 分数 × 0.1 − 5
  • 举例：90分→4.0 · 92分→4.2 · 85分→3.5 · 80分→3.0 · 60分→1.0
  • 总绩点 = Σ(绩点×学分)÷总学分，学分越高权重越大，高数4学分挂了比1学分选修狠4倍
  • 绩点影响：奖学金（综测学业占70%）· 转专业（硬门槛）· 考研复试（导师看成绩单）
  • 中量大没有保研资格，想读研只能考
  • 挂一科该科绩点变0，总绩点被大幅拉低；补考过了只算1.0还标"补考"，重修按实际分数算更划算
  • 累计挂科学分过多触发学业预警，严重的可能留级
  • 📚 绩点和选课直接挂钩 —— 怎么选看 选课指南 →

必做 考四级

  • 大一就能报名，每年6月和12月各一次
  • 四级过了才能考六级，越拖越不想考，趁高考英语底子还在早点考
  • 报名时间关注教务处通知

攻略 综测怎么算

  • 综测决定奖学金和评优排名，公式：品德20 + 学业70 + 综合能力10
  • 学业分 = 绩点 × 14（5.0×14=70满分），绩点3.5→49分，绩点4.0→56分，差0.5就差7分
  • 综合能力10分：班委/竞赛/论文/志愿加分，同一项取最高不叠加
  • 避坑：各学院细则不同，入学后找辅导员要；别参加收费野鸡比赛学院不认；奖状存电子版申报有截止日

攻略 考研看什么

  • 初试（笔试）：政治+英语+数学/专业课+专业课 = 500分，纯看分数跟绩点无关
  • 复试：过了初试线才进，导师会看本科成绩单，但重点盯专业课成绩
  • 别多门挂科（一门不要紧），成绩从低往高走比往下掉好
  • 有论文/省奖很加分，深度做一个项目比挂名一堆强
  • 初试分数是硬通货，比什么都管用

攻略 图书馆

  • 必须预约才能坐，系统预约+扫码签到入座
  • 超时未签到自动释放，用物品占座会被清理
  • 靠墙/靠柱的位子有插座，带电脑优先选
  • 两个馆：逸夫图书馆（西区）6:30-22:00，东区图书馆7:00-22:00
  • 借阅：本科生15册/人，借期30天，可续借1次续期30天
  • 咨询电话：86876595（流通）、86835722（参考咨询）

攻略 自习去处

  • 宿舍楼每层自习室：24小时开放，最近最方便
  • 图书馆自修室：6:30-22:00，需预约
  • 教学楼空教室：随时可用，考试周会紧张

攻略 早晚自习

  • 大一上学期各学院基本都有，但规定各学院不同
  • 大一下学期一般没有
  • 举例：去年理学院早自习周一到周五，晚自习是第二天有课就要上
  • 具体以入学后各学院通知为准

提醒 体测（10-11月）

  • 项目：BMI(15%) + 肺活量(15%) + 50米(20%) + 坐位体前屈(10%) + 立定跳远(10%) + 引体向上/仰卧起坐(10%) + 1000/800米(20%)
  • 具体时间看体育军事部通知

你可能不知道

  • 大课教室大家都坐中后排，基本在玩手机（大一直接当水课上）；迟到跟老师说一声就行，点名了才要紧
  • 有的课摸清点名规律就能翘，期末周认真补别挂科就行
  • 人工智能网课记得考试，不考直接挂科；刷课技巧找学长学姐问
  • 入党流程约2-3年，大一入学就递交申请书（越早越好），成绩排名很关键
  • 校园跑每学期要刷，参加3个活动免一半，多跑可加分
  • 宿舍可以挂床帘、贴墙纸、养绿植，管得不算严
  • 偶尔查寝，不会每天来

期末前
12月 - 1月

必知 冬训！不是开学军训

  • 1月11日-24日，在期末考试之后
  • 服装学校统一采购，在团支书/班长处登记尺码
  • 想缓训需医院证明+辅导员申请，缓训跟下一届补训
  • 军训后直接放寒假：1月25日起 🎉

必知 期末考试

  • 期末考试：1月4-10日
  • 总评低于60分=挂科，下学期开学初补考
  • 补考只看卷面分（平时分作废），通过按1.0绩点计
  • 补考不过要重修，跟下一届重新上课交作业考试
  • 累计挂科学分过多→学业预警，严重的可能留级

提醒 学生证福利

  • 国内大多数景区半价，杭州本地西湖免费、灵隐寺等半价
  • 发放时间关注学院通知

选看 考证规划

  • 英语四级（最推荐）— 大一就能报，先考四级；2026下半年（浙江）：9月10日10:00–9月28日17:00报名，笔试 12月12日，口试11月21-22日（选报）。报名在 cet-bm.neea.edu.cn，截止不补报。六级要四级 425 分以上才能报
  • 驾驶证（最推荐）— 随时报名，大学时间多趁早考
  • 计算机二级（选考）— 可以学一下计算机知识，考不考看个人

你可能不知道

  • 创新创业学分可以拿竞赛/论文/专利认定，A类国一能认定8学分，具体看知识库
  • 入党积极分子→发展对象需成绩排名班级40%内，别挂科

建议 户口迁不迁？

  • 迁的好处：在校补办身份证/办护照/考驾照不用回老家；毕业后留杭州落户更方便
  • 迁的代价：农村户籍迁出变城镇，村集体分红、土地、宅基地权益全没了，多数地区无法恢复
  • 不迁也行：全国已支持异地身份证补办和异地驾考
  • 如决定迁：带录取通知书+户口本+身份证到派出所开迁移证，报到时上交保卫处。户籍办电话：87676119

建议 行李打包

  • 床铺尺寸约 200×86cm（A床 86.5cm、其他床 86cm，各楼栋略有差别），被褥可网购寄学校（别从家扛）
  • 快递地址：浙江省杭州市钱塘区学源街258号中国计量大学（310018）
  • 28寸行李箱放得下，但宿舍没电梯，大件自己搬
  • 核心原则：人带到、钱带到、证件带到，大件发快递，日用品到校再买

选看 电脑选购指南

  • 轻薄本：一般够用，续航约10小时，携带轻便，上课带去带回不累
  • 游戏本：喜欢玩电脑游戏才需要，但续航只有约3小时，又重又沉
  • 打比赛需要什么配置不太确定，有需要的同学可以问学长学姐

必带 证件清单

  • 录取通知书 + 高考准考证（带着，可能要出示）
  • 身份证原件 + 正反面复印5张（A4纸）
  • 户口本复印件 每页复印2张
  • 学生档案 + 团员团籍证明（自带或高中邮寄）
  • 📦 要带的东西不止这些 —— 完整清单见 行李清单 →
  • 证件照 1寸2寸各一版，存好电子版（报名/社团/入党都要用）
  • 银行卡 + 少量现金500元备用

必做 报到当天流程

  • 报到时间：9/13 当天 8:00–20:00，别提前到（提前到进不了宿舍楼，只能住校外酒店）
  • 到校方式：直接问AI助手（豆包）查路线更准
  • 报到流程：①去学校后面那栋楼新生报到（签名+领袋子含新生手册）→ ②回宿舍整理床铺（装床垫、挂床帘、贴墙纸）→ ③缴费 → ④认识学长学姐
  • 拿快递：约舍友一起去，别一个人去！开学快递多又重，当天很热很累，问学长学姐怎么拿最方便（代拿vs自己拿）
  • 开学当天超热，记得带太阳伞！晚上有班会
  • 如果提前到：先把宿舍整理好（床铺、窗帘、改装），当天到的话先报到再整理
  • 🧳 报到当天要交的材料、要带的东西，对照 必带清单 →
  • 开学期间管得松，父母可以进宿舍楼

必看 校园卡怎么选

  • 先分清：这篇讲的是手机卡（运营商电话卡）；学校的电子校园卡（食堂一卡通，无实体卡）在「计量钉」App 领，是两回事
  • 月租：39元/月左右（含150G通用流量+视频会员）是常见档，别被忽悠办更贵的
  • 优惠期：优先长期优惠，短期的话1-4年皆可
  • 流量：注意区分通用和定向（定向只能刷指定APP，通用随便用），150G 通用够用
  • 违约金：选无违约金的，保留随时换卡的自由
  • ⚠️ 学长学姐那么热情推销是因为每张卡有50-80元佣金，按自己需求判断别被带节奏
