# 新生指南 · 开源版

一个**已真实运营**的大学新生指南静态站（中国计量大学 2026 级）的开源副本：13 个页面，纯 HTML/CSS/JS，**零构建、零依赖、零后端**。

> 线上版由在校学生利用课余时间维护；本仓库不含任何真实联系方式、群二维码与统计数据。

## 这个项目的几个设计点

1. **纯前端的可用性搜索** —— 无后端、无 API、无费用：首次搜索时抓取各页面源码自动建索引，两遍排序（精确匹配优先，不足时「两字滑窗」模糊兜底），搜不到时给出「提交需求」闭环（本地组装文本，自愿复制，不静默上报）。
2. **联系方式配置化** —— 全部收在 `config.js` 一处；默认留空时界面只显示占位说明，**源码里不存在任何真实联系方式**（静态站+开源天然会被爬虫收割，所以从机制上不让它出现）。
3. **隐私友好的行为统计（默认关闭）** —— 无 cookie、无用户 ID、不存 localStorage、不上传搜索词（像学号/手机号的输入一律过滤），只有匿名计数；`config.js` 保持默认时全程零网络请求。
4. **内容时效机制** —— 过期内容灰化+沉底而不是删除；首页「现在」区块按起止日期自动决定显示什么。
5. **深链接直达** —— 87 个社团、时间线 38 个条目、41 条问答都有锚点，适合「在群里直接甩链接」这种真实使用场景。
6. **昼夜双主题** —— 一套 CSS 变量全站换肤，手机端优先。

## 怎么运行

双击 `index.html` 就能用；或用任意静态服务器（例如 `npx serve`）。

## 怎么改成你自己的版本

1. 改 `config.js`：站名、微信号（想公开才填）、群码图文件名、统计开关；
2. 替换各页面内容（页面即数据，没有单独的数据库）；
3. 每页 `<body>` 末尾的脚本引用保持顺序：`config.js` 必须在 `contact.js` / `search.js` / `analytics.js` 之前。

> 本项目**仅供学习参考，不提供使用支持**：issue 不保证回复，fork 后的内容请自行核实时效性。

## 页面一览

| 页面 | 内容 |
|---|---|
| index | 枢纽页：搜索 + 「现在」 + 分组目录 |
| timeline | 入学时间线（38 个锚点，主力页） |
| luggage | 行李清单（120 项，三档强度） |
| course / curriculum / transfer / major | 选课 / 培养方案 / 转专业 / 专业五维评价 |
| club | 87 个社团总览（两层筛选 + 手风琴） |
| questions | 新生问答（41 条，可搜索） |
| contents / welfare / campus / sop | 目录 / 福利 / 校园生活 / 免打扰 SOP |

共享脚本：`theme.js`（昼夜切换）、`search.js`（搜索）、`contact.js`（联系卡）、`share.js`（分享）、`analytics.js`（统计）、`archive.js`（归档派生）。
